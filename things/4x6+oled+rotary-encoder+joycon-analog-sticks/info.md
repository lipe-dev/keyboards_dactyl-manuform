# Build Notes

## Right Hand

The right half was not printed from `DM_right.scad`. Instead, `DM_left_V7_final.scad` was printed a second time with a horizontal mirror applied in the slicer.

`DM_right.scad` was never used for printing, but it serves as a useful reference — it's essentially the original unmodified generated output (mirrored for the right hand), before any of the iterative OpenSCAD modifications made to the left.
